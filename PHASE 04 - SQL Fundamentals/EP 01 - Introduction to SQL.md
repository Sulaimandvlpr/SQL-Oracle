SQL (Structured Query Language) adalah bahasa yang digunakan untuk berinteraksi dengan database, termasuk untuk mendefinisikan struktur database, mengambil data, memanipulasi data, mengelola transaksi, dan mengatur akses.

Dalam repository ini, implementasi SQL yang digunakan adalah Oracle SQL.

Oracle SQL digunakan untuk mengelola informasi dalam Oracle Database. Dokumentasi resmi Oracle menyediakan SQL Language Reference sebagai referensi lengkap terhadap bahasa SQL Oracle.

Contoh paling sederhana:
```sql
SELECT *
FROM employees;
```
Query tersebut meminta Oracle untuk mengambil seluruh kolom dan baris dari tabel employees.
