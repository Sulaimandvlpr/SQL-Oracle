Untuk memahami SQL dengan baik, kita perlu mengetahui bahwa statement SQL dapat dikelompokkan berdasarkan fungsinya.

```SQL
│
├── DDL — Data Definition Language
│
├── DML — Data Manipulation Language
│
├── DQL — Data Query Language
│
├── TCL — Transaction Control Language
│
└── DCL — Data Control Language
```
Catatan: DQL merupakan istilah yang umum digunakan dalam materi pembelajaran, tetapi tidak selalu dipisahkan sebagai kategori tersendiri. SELECT sering dibahas sebagai bagian dari SQL query/DML dalam berbagai referensi.
